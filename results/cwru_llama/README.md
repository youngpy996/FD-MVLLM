# CWRU 1024-sample Llama experiment

该目录由原始 `results_accuracy_1024_Llama` 结果整理得到。

| 文件 | 内容 |
|---|---|
| `config.json` | 隐去本地绝对路径后的实验配置 |
| `summary.json` | 最佳验证指标、测试指标和训练时间 |
| `training_history.csv` | 50轮训练历史 |

关键结果：

- 最终验证轮次：50
- 最终验证准确率：99.42%（原始记录为0.9942954778671265）
- 最终验证Macro-F1：0.994672
- 测试准确率：98.9168%
- 测试Macro-F1：0.989330

说明：训练过程中第14轮的最高验证准确率为99.6577%，因此`summary.json`的
`best_validation`与第50轮最终验证准确率99.42%不同。本文档以最终验证结果作为
对外报告的验证准确率。

原结果目录中的checkpoint未通过归档完整性检查，因此没有作为可复现权重复制到此目录。
